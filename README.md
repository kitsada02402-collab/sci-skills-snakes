# บันไดงูทักษะกระบวนการทางวิทยาศาสตร์ 14 ทักษะ

เกมบันไดงูแบบเรียลไทม์สำหรับห้องเรียน เนื้อหาคือ **ทักษะกระบวนการทางวิทยาศาสตร์ 14 ทักษะ** (ขั้นพื้นฐาน 8 + ขั้นบูรณาการ 6) โจทย์มีภาพประกอบที่สร้างเป็น SVG ในหน้าเว็บ

- นักเรียน: เปิดหน้าแรก ใส่รหัสห้อง
- ครู: เปิด `#teacher` (ใช้รหัสผ่านครูชุดเดิมของระบบบันไดงูเคมี)

## วิธีเล่น (เล่นทีละคนตามลำดับ)
1. ทอยลูกเต๋า 2 ลูกจัดลำดับ (มีป๊อปอัปลูกเต๋าหมุนแล้วโชว์แต้ม) แต้มรวมสูงสุดเล่นก่อน
2. ถึงตาใคร คนนั้นกดทอยลูกเต๋า (ครูตั้งได้ 1 หรือ 2 ลูกต่อตา) → ตัวละครเดินทีละช่องตามแต้ม
3. จากนั้นถามคำถามคนนั้นคนเดียว ตอบถูกอยู่ช่องที่เดินมา (ช่อง ⭐ +2 ช่อง, บันไดขึ้น, งูลง) · ตอบผิดหรือหมดเวลากลับช่องที่เริ่มตา
4. ตาถัดไปเป็นของคนต่อไปในลำดับ จนมีคนถึงช่อง 100 หรือครบเวลาสูงสุดต่อกลุ่ม (ค่าเริ่มต้น 30 นาที)

## สถิติและการวิเคราะห์ (แท็บ "สถิติ/วิเคราะห์")
- **ภาพรวม**: % ถูกรวม แยกตามทักษะ ระดับ ห้องเรียน และข้อที่ตอบผิดมากที่สุด
- **รายบุคคล**: รายชื่อ (ห้อง/เลขที่) % ถูก จุดที่ควรเสริม กดดูรายละเอียดเพื่อเห็นข้อที่ผิด สิ่งที่ตอบ เฉลย และคำอธิบาย
- **รายข้อ**: ตัวเลือกแต่ละข้อถูกเลือกกี่คน ข้อสังเกตจากระบบ ใครตอบผิดและเลือกอะไร
- ดาวน์โหลด CSV: รายข้อ / รายบุคคล / ข้อที่ตอบผิด / ข้อมูลดิบ
- นักเรียนกรอกเลขที่ได้ตอนเข้าห้อง (ไม่บังคับ) ต้องใช้ `FIREBASE-RULES.json` ฉบับล่าสุด ถ้ายังไม่อัปเดตกฎ ระบบจะให้เข้าห้องได้ตามปกติแต่ไม่บันทึกเลขที่
- ห้องที่เล่นก่อนอัปเดตไม่มีชื่อติดมา จะแสดงเป็น "ไม่ทราบชื่อ"

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (ไฟล์เดียว) |
| `bank-seed.json` | ธนาคารข้อสอบเริ่มต้น 98 ข้อ (14 ทักษะ × 7 ข้อ) |
| `FIREBASE-RULES.json` | ชุดกฎ Realtime Database (รวมของเดิม + ส่วน `sci14/`) |

## ตั้งค่าครั้งแรก
1. Firebase Console → Realtime Database → Rules → วางเนื้อหา `FIREBASE-RULES.json` ทั้งไฟล์ → Publish
   (ข้อมูลเกมนี้เก็บใต้ `sci14/` แยกจากเกมเคมีอินทรีย์ ส่วน `admins/` และ `config/teacherPass` ใช้ร่วมกัน)
2. เปิด `…/#teacher` ใส่รหัสครู → แท็บ **ธนาคารข้อสอบ** → กด **โหลดข้อสอบเริ่มต้น 98 ข้อ**
